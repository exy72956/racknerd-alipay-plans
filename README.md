## 支付宝付款这一步，卡在哪

**第一是通道。** 有些商家说的“支持支付宝”是自己找人代付，你付完还要等对方手动开通。正规做法是在结账页直接调起支付宝收银台，扫码或输密码，钱进商家账户、订单自动变成已付。Evoxt 就把这一点写得很清楚：正式集成，不是第三方代付。RackNerd 的公开页面没有支付方式列表，你注册后走到结账页，看付款方式里有没有 Alipay 一栏，两分钟就能确认。

**第二是币种和汇率。** RackNerd 标价是美元。用支付宝付美元账单，实际扣款按提交时的汇率折算，一般会比你按中间价心算的略高一点，差额来自跨境结算成本。VMISS 那边是加元结算，其作者在教程里也提到同一现象。想算得准，以下单页显示的人民币金额为准，别拿搜索引擎里的汇率乘一遍就付款。

**第三是绑卡要求。** LightNode 在自家页面明确写了不要求绑定信用卡，这一点对只想用支付宝的人很关键。RackNerd 是否同样不要求，公开页面上查不到，结账页会写清楚。看到“必须绑卡”就别往下走。

**流量口径没写明。** RackNerd 页面只写 monthly transfer，没说明上传和下载是否合并计算。Evoxt 明确是双向计费，上传下载都算进去。同样标 5 TB，双向计费和单向计费的实际可用量能差一倍，按双向预留余量更稳。

**退款条款没公开。** RackNerd 公开页面上没看到成文的退款期限。作为参照，Evoxt 是 7 天、从部署第一台服务器起算，VMISS 是新购 7 天内且未明显使用可退、续费订单不退，LisaHost 主打 48 小时无条件退款。RackNerd 这一项请你下单前到条款页确认，不要默认它有。

**系统崩了不用求人。** ctrl 面板能重启和重装系统，带 HTML5 VNC 控制台，也能重置 root 密码。这些都是自助的，不用等工单。

## 常见问题

**支付宝付款要额外手续费吗？** 商家一般不单收一笔手续费，但你实付的人民币按提交时汇率折算，跨境结算会让它比中间价略高。以结账页金额为准。

**付款后多久能用？** RackNerd 官网写的是付款后即时开通，开通信息发到注册邮箱，登录 ctrl 面板也能看到 IP 和 root 密码。

**没信用卡能买吗？** 取决于结账页是否提供支付宝。这一步只能在结账页确认，公开页面没有清单。

**以后配置不够能升级吗？** 可以升到上一档，官方说明升级只需重启一次，约 1 分钟停机。

**能要 IPv6 吗？** 洛杉矶和法国机房可以免费申请，最多 100 个，下单后开工单。

**买完怎么连？** 邮箱里有 IP 和 root 密码，本地用 SSH 客户端连。系统起不来就用 ctrl 里的 HTML5 VNC。
